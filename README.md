MOMENTUM is a highly aesthetic and personal habit-tracking web application designed to help users build consistency over a 28-day cycle. Unlike generic trackers, it's built to be a beautiful, shareable, and permanent home for your goals.

Its core function is to let users select up to three habits—either from a rich list of 25 pre-defined goals or by creating their own—and track their daily progress on a simple 28-day grid.

Unique Features=>

Aesthetic & Thematic Personalization: Users can choose from multiple themes (like Pastel Sky Blue, Lavender, and Lemon Yellow), which change the app's entire color palette and add a beautiful, corresponding landscape background image.

Permanent Cloud Storage: All progress is saved permanently in a Firestore database, not just in the browser. This means users can access their data from any device.

Instantly Shareable with Private Profiles: Because it's a live website (deployed on Vercel/GitHub), you can share the link with anyone. The app automatically creates a unique, private, and persistent cloud profile for every new user, so their progress is saved securely and separately from yours.

At-a-Glance Progress Charts: Each habit card features a dynamic donut chart that provides an immediate, at-a-glance summary of the user's overall completion percentage for the 28-day cycle.

Built-in Motivational System: 
    Milestone Celebration- The app automatically celebrates 7, 14, 21, and 28-day streaks with a special 🌟 emoji on the grid.

   Daily Encouragement- Every time a user marks a day as complete, they receive an instant pop-up message with motivational quotes or fun "Gen Z slang" to make the process more engaging.

Qualitative Tracking: Users can do more than just check a box. A built-in notes feature allows them to add personal reflections, wins, or challenges to any day, adding valuable context to their journey
